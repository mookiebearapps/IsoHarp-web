# IsoHarp-web

An HTML5 Isomorphic Harp musical toy instrument. Built with the Web Audio API, this application features a multi-touch interface for expressive play.

## Features
* **Isomorphic Layout:** Notes are arranged in a consistent, logical grid pattern.
* **Multi-Touch Support:** Play multiple notes simultaneously on touch devices.
* **Custom Synthesis:** Utilizes built-in oscillators featuring multiple instrument profiles (piano, flute, square wave, xylophone, and a warm pad).
* **Spatial Audio:** Includes stereo panning that tracks across the horizontal grid position.
